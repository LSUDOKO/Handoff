Why does this only fire while the app is open?

The scheduler is a loop inside this process — no second service to install, no message bus. That's the right trade for a laptop, but it means a workflow only fires while Handoff is running.

For schedules that must fire whether or not your machine is awake, deploy to AgentCore Runtime and let EventBridge own the cron: python infra/eventbridge_setup.py --list.
